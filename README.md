# Convertidor de Archivos

Aplicación de escritorio para Windows que permite convertir archivos entre distintos formatos de forma local.

## Versión actual

**1.0.1**

## Características

- Conversión de imágenes
- Documentos de texto
- Hojas de cálculo
- Presentaciones
- PDF
- Libros y formatos de marcado
- Archivos comprimidos
- JAR
- Contenedores de Minecraft
- Conversión múltiple
- Previsualización de archivos
- Motores locales incluidos en el instalador

## Motores utilizados

La aplicación puede utilizar:

- LibreOffice
- ImageMagick
- 7-Zip
- Pandoc
- PDFium
- Aspose.PDF
- Microsoft Office, cuando está disponible
- WinRAR, cuando está disponible

## Instalación

La aplicación está disponible para **Windows de 64 bits**.

[Descargar Convertidor de Archivos 1.0.1](https://github.com/RobDev512/ConvertidorArchivos/releases/download/v1.0.1/ConvertidorArchivos_Setup_1.0.1.exe)

Ejecuta el instalador y sigue los pasos indicados.

No es necesario instalar Python ni los motores incluidos por separado.
