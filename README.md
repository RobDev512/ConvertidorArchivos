# Convertidor de Archivos

Aplicación de escritorio para Windows que permite convertir archivos entre distintos formatos de forma local.

## Versión actual

**1.0.1**

## Características

- Conversión de imágenes
- Documentos de texto
- Hojas de cálculo
- Presentaciones
- PDF
- Libros y formatos de marcado
- Archivos comprimidos
- JAR
- Contenedores de Minecraft
- Conversión múltiple
- Previsualización de archivos
- Motores locales incluidos en el instalador

## Motores utilizados

La aplicación puede utilizar:

- LibreOffice
- ImageMagick
- 7-Zip
- Pandoc
- PDFium
- Aspose.PDF
- Microsoft Office, cuando está disponible
- WinRAR, cuando está disponible

## Instalación

Descarga la versión más reciente desde la sección **Releases** del repositorio y ejecuta:

`ConvertidorArchivos_Setup_1.0.1.exe`

El instalador incluye los motores necesarios para las funciones principales.
